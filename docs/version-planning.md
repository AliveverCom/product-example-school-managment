# 版本规划

## 1. 大版本规划

| 版本号 | 版本说明 |
|--------|----------|
| v1.0 | 实现基础的增删改查功能 |
| v2.0 | 在 v1.0 基础上增加易用性功能，例如批量导入、考试状态修改等 |

## 2. 版本功能描述

### 2.1 v1.0 版本

v1.0 版本的目标是逐步完成基础增删改查能力，拆分为以下小版本：

| 版本号 | 版本说明 |
|--------|----------|
| v0.1 | 只实现前端程序，不连接后端 |
| v0.2 | 实现后端程序和数据库的基础结构，但暂时不与前端连接；此阶段的后端为假后端，只返回固定的样例数据，不实现真实的后端业务逻辑 |
| v0.3 | 将前端与假后端连接起来；前端显示的数据来自后端接口返回，但这些数据仍为后端硬编码的样例数据，不是真实数据库数据 |
| v0.4 | 实现前端、后端和数据库的真实集成；后端实现基础的增删改查功能，前端可以正常显示后端返回的真实数据库数据；同时在数据库中插入样例数据，并创建数据库初始化脚本 |
| v0.5 | 完成后端所有相关脚本，并进行单元测试；测试完成后根据测试结果进行 Bug 修复 |
| v0.6 | 完成后端所有服务的集成测试，并根据集成测试结果进行 Bug 修复 |
| v0.7 | 完成 End-to-End 测试；所有 End-to-End 测试由人工执行，人工测试后需提供 Bug 列表，后续根据该 Bug 列表进行问题修复 |

说明：v0.1 至 v0.7 是 v1.0 开发过程中的内部阶段性里程碑，并不直接等同于对外发布版本。v0.7 完成后，是否增加额外小版本或进入 v1.0 发布准备阶段，将根据实际交付情况另行确定。
